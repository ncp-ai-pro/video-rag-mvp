이 영상에서 Conditional Edge가 필요한 이유를 실습 흐름 기준으로 설명해줘.
Conditional Edge는 검색 결과의 품질과 답변 가능 여부에 따라 다음 노드를 다르게 선택하기 위해 사용합니다. 이 영상에서는 질문을 받은 뒤 검색기를 호출하고, 관련 문서가 충분하면 답변 생성으로 넘어가며, 부족하면 쿼리 재작성 또는 fallback 경로로 이동하는 구조로 설명합니다.

그럼 일반 RAG 체인과 가장 큰 차이는 뭐야?
일반 RAG 체인은 검색 후 바로 생성으로 이어지는 고정 경로입니다. LangGraph 기반 구성은 `state`를 보고 검색 재시도, 답변 생성, 종료 같은 경로를 선택할 수 있어 실패 상황을 UI에서 더 투명하게 보여주기 좋습니다.
