# Video RAG MVP 기획

## 목표

여러 YouTube 채널을 개인 라이브러리로 등록한다. 모든 영상은 제목·설명 기반으로 빠르게 찾고, 사용자가 선택한 영상만 자막 또는 STT로 분석해 질문과 재생 시간 근거를 제공한다.

## 이번 MVP에서 되는 것

1. 채널 URL을 등록하고 `yt-dlp`로 영상 메타데이터를 탐색한다.
2. 제목·설명 embedding 유사도로 분석하지 않은 영상도 추천한다.
3. 사용자가 누른 영상만 분석 Worker 큐에 넣는다.
4. 분석이 끝난 영상에 질문하면 답변과 최대 3개의 실제 시간 구간 링크를 반환한다.

## 의도적으로 제외한 것

- 여러 사용자의 계정, 결제, 공개 서비스 인증
- 분석하지 않은 영상의 내용에 대한 답변 또는 시간 구간 주장
- YouTube 전체 검색 및 자동 추천 문구 생성
- 모든 과거 영상의 자동 STT

## 사용자 흐름

```text
채널 등록 → 메타데이터 탐색 → 제목/설명 검색 → 분석할 영상 선택
→ 분석 작업 등록 → 자막/STT 및 embedding 완료 → 질문 → 답변과 재생 구간 확인
```

## 작업공간과 접속

- 첫 접속 시 서버가 익명 작업공간과 8자리 코드를 자동 생성한다.
- 브라우저에는 `HttpOnly`, `SameSite=Lax` 세션 쿠키만 저장한다. JavaScript는 토큰 값을 읽지 않는다.
- 같은 브라우저는 쿠키로 이전 작업공간을 자동 복원한다.
- 다른 브라우저·모바일에서는 사용자가 `기존 작업공간 연결`에 코드를 입력해야 같은 작업공간으로 전환된다.
- OS·하드웨어·브라우저 지문으로 사용자를 추적하지 않는다.

## 성공 기준

- 메타데이터 검색 결과는 제목·설명 기반임을 화면에 표시한다.
- RAG 답변의 각 근거는 `video_id`, `start_seconds`, `end_seconds`를 가진다.
- 영상 자막이 없거나 외부 API가 실패하면 `analysis_error`에 원인이 남는다.
- 사용자가 선택하지 않은 영상은 음성 다운로드·STT·자막 chunk embedding을 실행하지 않는다.
