Public ALB와 Private ALB 사이에서
요청이 어떻게 갈라지는지 비교

두 안 모두 Web Server는 공개 진입을 받고, General API WAS와 Chat WAS는 Private ALB 뒤에 둡니다. 아래 버튼으로 정적 화면·API·Chat 경로만 남겨 볼 수 있습니다.

공통: Analysis Worker는 어느 ALB·Listener·Target Group에도 연결하지 않고 PostgreSQL jobs를 직접 polling합니다.

핵심 판단 안 A와 안 B는 Target Group을 실제로 쓰느냐의 차이가 아닙니다. Private ALB가 API·Chat WAS로 분기하려면 두 안 모두 Target Group이 필요합니다. 안 A는 운영·장애 대응용, 안 B는 발표 첫 화면용으로 쓰는 것이 적합합니다.
